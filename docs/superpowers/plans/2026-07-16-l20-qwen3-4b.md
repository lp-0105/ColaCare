# L20 Qwen3-4B Offline Preparation Implementation Plan

> **Execution:** Work through each task in order on `l20-qwen3-4b`. Run the named
> verification immediately after each implementation task and preserve earlier smoke paths.

**Goal:** Produce a pinned, integrity-checked offline transfer workflow and a deterministic
single-fixture Transformers BF16 smoke test for the school's NVIDIA L20.

**Architecture:** Keep the existing OpenAI-compatible Agent adapter unchanged for local Ollama
and future vLLM. Add a separate direct-Transformers entry point for the first L20 validation,
plus preparation/packaging/verification scripts and audit/runbook documentation. All runtime
outputs stay under ignored `artifacts/`.

**Tech Stack:** Python 3.10+, `huggingface_hub`, PyTorch, Transformers, POSIX shell,
GNU `tar`/`split`/`sha256sum`, `unittest`.
